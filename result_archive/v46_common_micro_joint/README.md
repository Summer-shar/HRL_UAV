## 当前判决

- TD3-SAC 相对 PPO-SAC 平均快 13.47 ms，三个训练种子方向一致；但训练种子层级 95% CI [-28.47, +1.53] ms 仍跨 0，因此只能判为当前更优候选，不能宣称显著胜出。
- TD3 学习轨迹相对同一微观策略的动态质心平均快 2.53 ms；逐训练种子净收益为 [0.23, 0.14, 7.23] ms，收益主要由一个训练种子贡献，尚未形成稳定的轨迹优势。
- PPO 学习轨迹相对自身动态质心的差值为 +0.15 ms，可视为宏观策略基本退化成质心跟踪。
- 结论：保留 TD3-SAC 作为后续主方法候选；先修复连续联合更新造成的微观策略遗忘，并重新验证轨迹净收益，再开展 CPU 与任务负载矩阵。当前结果不支持直接启动大规模对比实验。
