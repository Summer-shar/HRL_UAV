# v65 克隆迁移微调门禁结论

**判决：FAIL。**

本实验只验证一个问题：v56 在超不均衡场景训练的克隆 Actor，能否作为 v64 中等负载场景的初始化，并通过纯微观 SAC 在线微调达到可用水平。宏观始终固定为动态质心。

| 方法 | 加权端到端时延 / ms | 队列 / Mbit |
|---|---:|---:|
| v56克隆（未微调） | 1173.71 [1090.16, 1257.26] | 38.27 [33.80, 42.74] |
| v65克隆+在线微调 | 1299.07 [1008.37, 1589.77] | 50.89 [32.24, 69.54] |
| 因果QA-PSCA | 602.89 [595.77, 610.01] | 9.72 [9.20, 10.24] |

## 结论边界

- 失败的是跨场景迁移方案，不是对 SAC 在同场景内可学习性的最终否定。
- v56 克隆携带超不均衡场景的路由先验；负载分布改变后，它不是可靠的初始化。
- 在线微调没有在冻结预算内修复该偏差，因此不进入位置门禁或 PPO 联合训练。
- 若继续教师路线，教师数据必须在最终冻结场景内生成，并在论文方法中明确披露。
