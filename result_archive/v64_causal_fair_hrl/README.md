# v64 因果公平 HRL 实验归档

本目录归档 v64 的训练、20 个共同随机环境种子评估、宏观层反事实和完整 2x2 分层归因结果。详细分析见 [COMPLETE_ANALYSIS_CN.md](COMPLETE_ANALYSIS_CN.md)，简表见 [RESULTS_CN.md](RESULTS_CN.md)。

## 核心结果

| 方法 | 平均端到端时延 (ms) | 平均队列 (Mbit) | 平均功率 (W) |
|---|---:|---:|---:|
| 因果 QA-PSCA | **620.232** | **9.766** | 827.426 |
| PPO + QA 锚定残差 SAC | 630.965 | 10.074 | 827.368 |
| PPO + Direct SAC | 742.861 | 15.394 | 828.199 |
| Random | 2748.238 | 151.900 | - |
| No-Coop | 4370.369 | 471.394 | 831.160 |
| Xu-CVX 适配版 | 8910.790 | 1216.112 | - |

以上均值来自同一训练种子 `seed=1` 的最终 checkpoint，并使用 20 个独立 CRN 环境种子 `8000-8019` 评估。它们不是 20 个训练种子的结果。

## 已验证结论

- QA 锚定残差架构相对 Direct SAC 改善 **111.896 ms**，95% CI `[-127.958, -95.834]`。
- 但同一 PPO 下，学习残差相对纯 QA 锚点反而增加 **10.477 ms**，95% CI `[8.870, 12.084]`。
- 同一残差 SAC 下，学习 PPO 轨迹相对动态质心增加 **0.456 ms**，95% CI `[0.088, 0.824]`。
- 因而当前最优方法是因果 QA-PSCA；v64 的两个学习层均未证明超越各自锚点。
- Direct SAC 的主要失败模式是低负载任务过度转发；残差方法的优势主要来自 QA-PSCA 锚点，不是学习残差本身。
- PPO 仅在动态质心附近偏移约 2.24 m，轨迹视觉接近重合，未学出有价值的宏观协作部署。
- 队列保持稳定，训练确实收敛；问题是收敛到的策略性能不优，而不是训练没有运行。

## 证据边界

该实验可以证明架构、训练流程和队列稳定性，也可以证明 QA 锚点显著改善 Direct SAC；不能据此声称完整 HRL 已超过 QA-PSCA，不能声称 PPO 学出了有效轨迹，也不能声称具有多训练种子稳健性。
