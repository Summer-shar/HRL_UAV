## TD3-SAC 配对比较

- PPO-SAC - TD3-SAC = -11.89 ms，95% CI [-17.87, -5.90]，TD3-SAC更慢。
- PPO-SCA - TD3-SAC = +1908.46 ms，95% CI [+1729.40, +2087.53]，TD3-SAC更快。
- No-Coop - TD3-SAC = +3713.23 ms，95% CI [+3541.98, +3884.49]，TD3-SAC更快。
- 固定初始站位 - TD3-SAC = +49.67 ms，95% CI [+23.92, +75.43]，TD3-SAC更快。
- 动态质心 - TD3-SAC = +65.75 ms，95% CI [+34.27, +97.23]，TD3-SAC更快。

## 筛查结论

- 本轮第一名为 PPO-SAC；相对 TD3-SAC 平均快 11.89 ms，95% CI [5.90, 17.87]。
- TD3-SAC 排名第二，但显著优于固定初始站位、动态质心、PPO-SCA 和 No-Coop。
- 该结论基于每种学习方法 1 个训练种子；正式论文强主张仍需补多个训练种子。
- PPO-SAC、PPO-SCA 与动态质心的绝对轨迹接近重合，但轨迹数组和网络参数均不相同；三者都学成了近似质心跟踪，差异见 `05_轨迹差异放大.png`。
