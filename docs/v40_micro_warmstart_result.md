# v40 微观 SAC 暖启动结果（FROZEN RESULT）

## 判决

**PARTIAL_PASS_QUALITY_ONLY：最终质量通过，尾段稳定性未通过。**

本实验严格使用 `final.pt`，未按中间结果选择 checkpoint。初始化审计证明仅继承 v33 Actor；
Critic、target Critic、温度、三个优化器和 replay 均为全新状态。

## 机制结论

1. 旧 Actor 在新场景和新目标下本身保持良好：前 50 轮 Actor 冻结时评估稳定在 687.25 ms。
2. Actor 解冻后的首批梯度会快速破坏好策略；因此“冷启动初始策略差”不是唯一根因。
3. 暖启动能避免 v39 的永久退化，并在 300 轮 final 上获得显著更好的时延，但恢复过程剧烈、尾段仍未达到预注册稳定标准。
4. 熵温度从 0.100 平滑降至 0.083，无失控证据；问题集中在困难队列分布下的 Critic/Actor 更新稳定性。

因此，v40 可作为后续修复的起点，但不能被表述为“微观 SAC 已稳定收敛”，也不应立即据此启动完整宏观正式训练。
