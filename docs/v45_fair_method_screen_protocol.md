# v45 四方法公平筛选协议（FROZEN）

> 状态：FROZEN。本文档在正式训练与统一评估之前建立；看到结果后不得修改训练预算、检查点规则、评估种子或主指标。

## 1. 目的

在最终软目标、增强负载不均衡和 RPGM 用户移动场景下，公平比较：

1. TD3-SAC（本文方法）；
2. PPO-SAC（宏观算法替换）；
3. PPO-SCA（微观算法替换）；
4. No-Coop（禁用 UAV 间协作）。

固定悬停和动态质心跟踪仅作为零训练参考策略，不参与学习方法的训练预算比较。

## 2. 冻结训练协议

- 训练种子：`seed=1`。本轮是方法筛选，不把 20 个评估种子误称为 20 个训练重复。
- 第一阶段：300 episode；微观策略冻结，只训练宏观策略。
- 第二阶段：200 episode；从第一阶段最终宏观检查点继续。
- TD3-SAC 和 PPO-SAC 在第二阶段以相同的低学习率继续微观 SAC；PPO-SCA 始终使用同一 SCA 求解器；No-Coop 始终禁用 U2U 协作。
- 所有方法共用相同环境、负载、RPGM 移动、CPU、通信模型、软目标和评估频率。
- 检查点固定取第二阶段第 200 episode 的 `final.pt`，禁止按结果挑选 `best` 或中间 checkpoint。
- TD3-SAC 复用已经按同一 300+200 协议完成的 v43/v44 模型；其余三种方法在 v45 中补齐同预算训练。

## 3. 冻结评估协议

- 共同随机种子：`8000-8019`，共 20 个 CRN episode。
- 每种策略在每个种子上使用完全相同的用户移动、任务到达和信道随机流。
- 主指标：优先级加权端到端时延，越低越好。
- 次指标：高/低优先级时延、队列积压、软目标、平均功率、协作比例、U2G 距离和推理时间。
- 统计：报告逐种子原始值、均值、95% CI，以及各基线相对 TD3-SAC 的配对差值和 95% CI。
- 排名首先按平均端到端时延；软目标与功率只作次级解释，不设硬功率门槛。

## 4. 结果边界

- 单训练种子结果只能用于筛选和形成论文初步图，不能单独支持“算法普遍最优”的强统计主张。
- 若 TD3-SAC 不是第一，不修改数据、方法标签或比较口径；先检查差异是否显著，再决定算法改进或收窄论文主张。
- 只有筛选通过后，才对最关键的方法补做不少于 3 个匹配训练种子的正式统计。
