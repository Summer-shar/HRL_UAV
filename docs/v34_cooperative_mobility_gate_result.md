# v34 群组移动与协作轨迹门禁结果

## 1. 场景定义

- 地面终端采用 RPGM-inspired 群组相关移动：每个区域具有平滑转向的移动业务热点，区域内终端在热点周围进行独立相关运动。
- 不设置圆形区域硬边界；仅保留 `0--1000 m` 仿真地图边界。
- 热点名义速度为 `0.45 m/s`，终端实测平均速度为 `0.488 m/s`。
- 负载采用三阶段循环切换，总负载不变，`load_scale=1.15`。
- CPU 为 `10 GHz`，功率仅作为 `0.1` 权重的软目标；不设置硬功率门槛。
- 三种固定宏观策略共用同一个冻结 SAC 微观策略与共同随机数：
  1. 固定初始站位：首次靠近初始业务质心后悬停；
  2. 动态质心跟踪：仅考虑本区域 U2G 服务；
  3. 协作感知移动：在质心目标上增加因果协作残差，使轻载支援机靠近当前重载机。

## 2. 移动模型审计

3 个审计种子的 300 秒结果：

- 终端平均速度：`0.488 m/s`；
- 终端平均路径长度：`146.33 m`；
- 平均直线度（净位移/路径长度）：`0.711`，旧版近直线轨迹约为 `0.989`；
- 区域热点平均净位移：`103.37 m`；
- 区域内终端 RMS 离散度：`50.60 m`；
- 地图边缘命中比例：`0`。

移动审计判决为 `PASS`：轨迹具有平滑弯曲、群组整体移动和区域内个体差异，不存在圆边界堆积。

## 3. 零训练门禁

使用 20 个共同随机种子（`2000--2019`）进行纯重放，结果如下：

| 策略 | 加权端到端时延 / ms | 平均队列 / Mbit | 平均功率 / W |
|---|---:|---:|---:|
| 固定初始站位 | 681.452 | 5.895 | 824.415 |
| 动态质心跟踪 | 663.153 | 6.519 | 838.545 |
| 协作感知移动 | 659.758 | 6.057 | 866.116 |

配对结果：

- 质心跟踪相对固定站位改善 `18.30 ms`；
- 协作移动相对质心跟踪改善 `3.40 ms`，差值 95% CI 为 `[-5.06,-1.74] ms`；
- 协作移动相对固定站位改善 `21.69 ms`，差值 95% CI 为 `[-24.63,-18.76] ms`；
- 协作移动同时将平均队列从 `6.519 Mbit` 降至 `6.057 Mbit`。

## 4. 判决边界

- 科学结论：`UAV 移动优于固定站位`，且 `协作信息提供了质心跟踪之外的小而系统性的额外收益`。
- 预注册门禁要求协作相对质心的平均收益严格大于 `5 ms`。实测为 `3.40 ms`，因此严格门禁判决仍为 `FAIL`。
- 该失败只表示协作增量未达到预设实用阈值，不得改写成“协作移动无效”；其配对 CI 已排除 0。
- 功率是描述性软目标。当前手写 `90 m` 残差以约 `27.6 W` 的平均功率增量换取 `3.40 ms` 时延收益，不应直接作为最终算法策略。

## 5. 后续约束

- 不再回调移动速度、负载、残差幅度或 `5 ms` 判据来追求门禁通过。
- 正式 HRL 的任务应是学习状态相关残差，在保持质心跟踪收益的同时，只在协作收益足以覆盖移动与能耗代价时移动。
- 在正式长训练前，先做单种子短 pilot，验证联合训练曲线稳定且最终策略至少不劣于动态质心跟踪；否则停止，不进入多种子矩阵。
