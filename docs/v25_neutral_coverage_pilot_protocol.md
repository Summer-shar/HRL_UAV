# v25 联合中性动作覆盖单因素 Pilot 协议

> 状态：FROZEN FOR PILOT
>
> 日期：2026-08-04
>
> 本协议在任何覆盖训练结果产生前冻结。它只验证宏观联合零残差覆盖，不授权 formal。

## 1. 目的

检验 v24 动态对偶已经抑制部分无效机动后，持续的联合中性动作覆盖能否进一步修复
“联合零残差样本稀缺 -> Critic 外推 -> Actor 漂移”的反馈环，并回收当前学习轨迹与
同口径动态质心参考之间的大部分性能差距。

## 2. 单因素定义

对照使用已冻结的 `tcom_dynamic_u2u_sparse_v24_dual_on` pilot。实验臂使用
`configs/tcom_dynamic_u2u_sparse_v25_dual_neutral_coverage.json`。除结果目录、外部微观
checkpoint 目录和 `td3_neutral_episode_probability` 外，训练参数完全一致。

| 项 | v24 对照 | v25 覆盖 |
|---|---:|---:|
| 系统动态对偶 | 开 | 开 |
| `energy_dual_lr` | 1.0 | 1.0 |
| 固定功率罚项 | 0 | 0 |
| TD3 target noise | 0.05 | 0.05 |
| 联合中性 episode 比例 | 0 | 0.25 |

覆盖规则冻结如下：

1. 使用独立于训练主 RNG 的确定性随机流，以 seed=1 选择中性 episode；
2. 被选中的整个 episode 内，三架 UAV 的全部宏观动作均为联合零残差；
3. 零残差表示跟踪当前动态业务质心，不是冻结 UAV，也不绕过 20 m/周期位移上限；
4. 覆盖在 warm-up 和 Actor 训练阶段持续存在，不只注入早期回放；
5. 非中性 episode 完全沿用 v24 的 warm-up/episode-persistent exploration；
6. 评估阶段不注入覆盖动作；覆盖样本正常进入 replay，不增加 BC 或动作正则损失。

## 3. 训练与评估预算

- 训练 seed：1；
- 复用 v24 `dual_on` 的微观 SAC best checkpoint，不重新预训练微观层；
- 联合 TD3-SAC：从干净 Actor、Critic、优化器、宏观 replay 和 lambda=0 开始 100 episodes；
- 微观层沿用 v24 的联合慢更新协议；
- 每 20 episodes 用固定种子 `1000--1019` 评估；
- 只允许本次 0.25 覆盖比例，不因结果调整概率或训练轮数。

来源：`result_archive/v24_centroid_reference_audit/summary.json`。

## 5. 验收

覆盖方案只有同时满足以下条件才判为通过：

1. **时延回收率不少于 80%**：最终 20-seed 加权时延不高于 `763.076310 ms`；
2. 覆盖相对 v24 对照的逐种子时延差 95% CI 完全低于 0；
3. **质心偏离回收率不少于 80%**：平均距动态质心不高于 `14.732044 m`；
4. 覆盖相对 v24 对照的逐种子质心距离差 95% CI 完全低于 0；
5. 最终系统功率 UCB95 不超过 `840 W`；
6. 覆盖 episode 实际比例、联合近零动作 replay 占比和所有数值/回归测试完整落盘。

辅助判读不改变判决：

- 距离通过而时延不通过：覆盖修复了漂移，但该修复不足以作为最终算法改进；
- 时延通过而距离不通过：收益存在，但不能归因为联合零动作覆盖修复；
- 两者均不通过：进入已登记的 Actor 局部优化/状态表征条件分支，不追加经验惩罚；
- 不得以延长本轮训练或修改 0.25 比例挽救失败结果。

## 6. 边界

- 本实验仍是固定负载动态用户场景，不与负载切换门禁数值直接比较；
- 不修改奖励、通信、CPU、动作投影、回放容量、探索持久性或 SAC 学习率；
- 不加入 Advisor、距离惩罚、移动惩罚或 BC 正则；
- pilot checkpoint 不得继承到 formal；三种子长训练继续禁止。
