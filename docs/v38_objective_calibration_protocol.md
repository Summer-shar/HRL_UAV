# v38 软目标权重校准协议（FROZEN）

## 目的

在不修改环境、策略或奖励的前提下，直接测量训练代理 `C_D` 与 `C_E`，核验
`0.25 ms/W` 的物理交换率对应的软目标权重。该实验只用于目标校准，不构成正式性能证据。

## 冻结项

- 交换率：每增加 20 W 平均功率，至少换取 5 ms 优先级加权端到端时延改善，
  即 `rho=0.25 ms/W`；
- 策略、微观 checkpoint、通信模型和移动模型与 v37 完全一致；
- 校准种子复用 `5000--5019`；正式门禁不得再次使用这些种子；
- 同时核验基准负载 `[12.5,5.5,3.5]` 与增强不均衡负载 `[14.5,4.5,2.5]`；
- 不根据结果调整交换率、负载、协作偏移或策略。

## 直接记录

逐微步记录并按 episode 聚合：`cost_delay`、未裁剪 delay proxy、`cost_energy`、
未裁剪 energy proxy、`overflow_cost`、`drift_cost`、完整 `J_step` 及两类 clipping 激活率。

## 机械推导

对每个操作点及两点合并样本，用过原点回归估计：

`k_D = Delta C_D / Delta D_ms`，`k_E = Delta C_E / Delta P_W`。

固定 `rho=0.25 ms/W` 后：

`r = w_E/w_D = rho * |k_D|/|k_E|`，
`w_D=1/(1+r)`，`w_E=r/(1+r)`。

## 冻结条件

只有同时满足以下条件才冻结机械计算所得的合并权重：

1. delay/energy clipping 激活率为 0；
2. overflow 与 drift 的策略间差值为 0；
3. `0.9*C_D+0.1*C_E+overflow+drift` 能逐种子重构旧 `J`；
4. 报告两个操作点各自的权重及跨度，不把跨工况稳定性写成未经测量的假设。

权重冻结后才允许修改配置和重新训练 SAC；正式门禁必须使用全新的 20 个 CRN 种子。
