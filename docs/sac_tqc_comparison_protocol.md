# SAC 与 TQC 配对试验协议

日期：2026-09-08。状态：运行前冻结。目的：检验 TQC 能否改善当前纯 RL 路由学习，而非预设 TQC 必须胜出。

## 比较对象

- 对照：PPO + Direct SAC，现有双标量 Q。
- 处理：PPO + Direct TQC，两个 Critic，每个 25 个分位数。
- 两臂各自从头训练，seed=1；不加载任何历史 Actor、Critic、优化器或 replay。
- 两臂 Actor、PPO Actor/Critic、初始熵温度及初始化后的全局 RNG 逐项核对相同。微观 Critic 输出维度不同，不声称其初始权重或 Q 值完全相同。
- 无 QA、教师、行为克隆、SCA 锚点、动作门控、规则回退或额外 shaping。路由可行域、投影和熵的原始分数动作语义不变。

## 固定预算与配置

- 每臂 200 窗口微观预训练 + 800 窗口 PPO/微观异频共同更新。每窗口 300 s；常规采样流连续 3 窗口后重置。
- 微观 Actor/Critic/温度学习率分别为 3e-5 / 3e-4 / 3e-5；开启 PPO 不改变 SAC 学习率、replay、优化器状态或 Actor warmup。
- 两臂均从第一轮开始每更新事件对同一 batch、同一 target 做两次 Critic 梯度拟合；Actor、温度、target、PPO 更新时钟保持相同。
- 批量 128、replay 100000、网络隐藏层 256×256、目标网络 tau=0.01、每资源帧 gamma=0.99；其余参数由运行前生成的两个 JSON 完整冻结。
- 场景保持 3 UAV、39 用户、10 GHz/UAV、U2U 总带宽 6 MHz、三区负载 [12.5,5.5,3.5] 的循环排列及 1.15 负载倍率。
- 奖励保持 0.9×加权未完成父任务持有代价/10 + 0.1×软能耗/14 的负代价，高低优先级 10:1。宏观与微观使用原有物理时间累计方式。
- 不调学习率、不改场景、不按中间性能提前停止或追加预算。非有限数、实现校验失败或墙钟上限触发时标记工程失败/不完整，不作性能裁决。

## TQC 数学语义

下一状态两头共 50 个分位数混合排序后，截去最大的 4 个，保留 46 个。用 transition 自带的物理折扣和下一动作熵项形成 46 个 target。当前两个 Critic 对所有 target 做分位数 Huber 回归，阈值 1，采用 SB3-Contrib 的全元素均值归约。Actor 使用当前两头全部分位数的均值，不截断、不取两头最小值。两次 Critic 拟合复用同一 batch/target。

这是 TQC 价值学习规则的成套处理，包含分布输出、损失、target 截断、Actor Q 聚合的变化，不声称是“只多了 24 个输出”的消融。更新时钟、优化器和动作投影适配本项目，不能称为未经改动的 SB3 默认配置。

算法依据：

- Kuznetsov et al., ICML 2020: https://proceedings.mlr.press/v119/kuznetsov20a.html
- 参考实现：https://sb3-contrib.readthedocs.io/en/master/_modules/sb3_contrib/tqc/tqc.html
- 损失语义：https://sb3-contrib.readthedocs.io/en/master/_modules/sb3_contrib/common/utils.html

## 评估与出图

- 训练场景按既有 continuous 日程配对。开发验证使用 33000、33001，不用于挑选最终权重。
- 预训练每 60 窗口和结束时只读验证；联训 final-only，期间保存权重，结束后回溯约总窗口 401/602/800/902/1000 的固定验证曲线。实际采样流边界写入索引，不伪造整百轮数。
- 最终配对场景为 34500–34504，每个连续 900 s；只有 1 个训练初始化，绝不称为 5 个训练种子。
- 两臂最终都评估完整方法、同一微观策略下的动态质心，以及不学习的均分诊断。配对核验用户轨迹和到达计数。
- 比较有限时域 J、加权完成时延、高低优时延、完成率、期末积压、平均计算/转发队列、晚段队列斜率、功率、实际运行时间和各自宏观增量。
- 条件于两个固定检查点，报告 5 个场景逐对差值及配对 t95 区间；不代替训练种子方差，不作多指标筛选后的正式显著性声称。
- 只用 final，不挑 best。1000 窗口未稳定则标记“预算内未收敛”，不能判成该方法理论上限；单种子优胜也不证明总体优胜。
- 训练奖励图保留原始线并标明后向平滑；固定验证图不平滑；最终配对图展示所有场景；队列图展示逐场景真实时间曲线。
