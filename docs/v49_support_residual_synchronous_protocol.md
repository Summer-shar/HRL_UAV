# v49 支撑集残差分层训练协议

状态：seed-1 门禁阶段。

## 目的

修复 v48 中下层 SAC 同时决定“是否启用链路”和“链路内分配比例”所造成的动态 MAC 不连续：任意极小的新链路概率都会增加活跃链路数，并把 3 MHz 总带宽重新均分。

## 算法

1. 每个资源帧由 SCA 生成稀疏基准路由及活跃链路支撑集。
2. SAC 输出 12 维优先级门控潜变量。
3. 将 SAC 相对零潜变量先验的对数比乘以 0.05，只在 SCA 已选链路内重加权。
4. SCA 未选链路严格保持 0，避免改变 `K_active`；各源路由行重新归一化。
5. replay 保存 SAC 的潜变量动作，奖励来自组合策略的真实环境执行结果，因此 SAC 持续学习而非冻结模仿 SCA。

## 训练公平性

- 每个含 SAC 的方法均独立进行 200 轮下层预训练。
- 前 200 轮上层不学习，统一采用零残差动态业务质心跟踪；第 201 轮起才解冻对应的学习型上层。
- 联合阶段 TD3/PPO 与 SAC 同步更新，不冻结下层。
- PPO-SCA 和 No-Coop 不使用残差结构。
- CPU、通信、移动、负载切换和软目标均与 v48 相同。

## seed-1 门禁

先跑 smoke，再进行 200 轮独立下层预训练和最多 800 轮 TD3-SAC 联训。门禁同时检查：

- 20 个 CRN 评估种子的端到端时延与队列稳定；
- 下层 Actor/Critic 和上层 TD3 均产生非零更新；
- 轨迹不存在无意义绕圈，且相对质心或固定位置有可解释收益；
- 支撑外链路概率逐帧为 0，动态带宽活跃链路数未被残差意外改变。

通过后才扩展到五训练种子、全部独立方法以及 CPU/负载敏感性矩阵。
