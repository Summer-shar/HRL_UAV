# v48 优先级门控同步分层训练协议

状态：seed=1 机制验证版。v47 结果只读保留，不覆盖。

## 改动依据

- v47 的 20 个共同随机种子反事实显示，TD3-SAC 在服务阶段将约 55% 的高优任务远端转发；SCA 基本保留本地。
- 将高优路由改为本地后，加权端到端时延由 710.93 ms 降至 663.05 ms，但低优时延上升，因此不采用硬规则作为最终算法。
- 同一微观策略交叉重放表明，微观路由解释约 48 ms，宏观轨迹解释约 5--9 ms。

## v48 单因素算法修复

微观 SAC 使用 `priority_gated` 动作：每个优先级、每个源 UAV 先学习一个本地/协作门，再学习协作目的地。高优门的零动作先验由已有 10:1 时延权重机械给出：

`p_local,H = sigmoid(log(10)) = 10/11`，`p_local,L = sigmoid(0) = 1/2`。

门控仍由 Actor 连续控制，不是高优本地硬约束。动作从 18 维非唯一投影降到 12 维有语义潜变量。

联合阶段 SAC 每 5 次更新学习一次 Actor，学习率为 actor `1e-5`、critic `1e-4`，并从联训开始持续更新；上层和下层均不冻结。

## seed=1 判据

1. 高优远端比例显著低于 v47，且不是恒定值；
2. 端到端时延不高于 v47 的 710.93 ms，目标是接近或优于 663 ms 反事实水平；
3. 低优时延不得出现高优全本地反事实的系统性恶化；
4. 联合阶段上下层参数均有持续更新记录；
5. 通过后才扩展到其余训练种子和所有公平基线。
