# Critic 拟合次数续训结果

日期：2026-09-08。状态：两臂训练及末次评估完成，总计 25.20 分钟。

## 结论

普通算法从 1200 轮续训到 1400 轮，加权完成时延从 638.35 降到 602.74 ms。不能用此前 1000 到 1200 轮改善较小，推断后续训练无价值。

在相同起点、相同新增 200 轮预算下，每个更新事件对同一 batch 和固定 target 拟合两次 Critic，得到 598.17 ms，相对普通续训再改善 4.57 ms。三个开发评估场景的加权时延和软目标 J 均改善。这是本次续训对照的正面证据，不证明该修改普遍有效，也不证明 Critic 排序错误已被修复。

- 同一源：`results/ppo_only_unlock_continue800_to1200_seed1/at1200/final.pt`。
- 源 SHA256：`6b3d8f52f31b6a96e739a7e8cb48259207373a4ae66b5e318082c7fab2b32ee3`。

- 每个场景连续评估 900 s，使用最后权重，不挑中间 checkpoint。

不能说所有分项、所有场景都改善：33502 的低优时延增加约 4 ms。不能把这三个开发场景当作正式多训练种子显著性证据。

## 尚未解决的问题

1. PPO 尚无正增量。同一末次 SAC 下，PPO 比质心慢 0.7870 ms，J 高 0.003176，功率高 3.3093 W。这次整体进步不能归因为学到了更好的协作轨迹。
2. 完整 PPO+SAC 的加权时延均值比均分低 3.26 ms，但 J 仍高 0.000604，低优时延仍高约 168 ms。不能宣布完整方法在所有目标上胜过均分。
3. 同一 SAC 配质心时，其加权时延与 J 均值分别比均分低 4.04 ms、0.002572，但低优时延仍较高；这属于优先级加权目标下的折中，不是所有任务都更快。
4. 两次拟合完整方法的末段队列斜率在三个场景分别为 +0.01830、-0.00767、-0.00042 Mbit/s。没有出现原先数秒至数十秒的崩溃，但有限 900 s 重放不能证明长期队列稳定或最终收敛。
5. 训练奖励曲线仍有波动，且包含随机动作及场景切换。末次确定性评估变好不等于训练曲线已经严格收敛，不承诺继续训练一定继续降低。
