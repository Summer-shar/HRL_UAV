# 固定协议与路径

`hrl_v2/configs/v2_1_0.json` 和 `physical_scene.json` 是包内资源。可使用训练入口的 `--config` 指向另一份相同协议文件，但哈希校验不允许无记录改变科研协议。

本次仅移除了 `runtime.preserve_local_python` 绝对路径字段；其他JSON值、物理场景字节、奖励、状态、动作、网络、有效batch、学习率、更新次数和日程均保持。旧设计配置的状态描述是历史元数据，实际工程状态见项目README。

代码身份按包内相对路径和字节哈希计算；源码安装位置不参与身份。工作目录独立于安装位置，包含 `validation/` 和 `v2_runs/`。验证/恢复仍检查Python、PyTorch、NumPy、CUDA、显卡及确定性设置，只去掉解释器路径和操作系统版本字符串的绑定。

本地运行必须先验证。换配置、源码、数值环境会使原验证记录失效；不会自动减batch、截历史、删队列、换后端或启动旧备选参数。
