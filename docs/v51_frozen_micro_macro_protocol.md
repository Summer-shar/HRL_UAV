## 0. 定位与终止条款

- 本实验是**方法路线的最后一次尝试**。无论判决如何，不再开设 v52 及后续方法实验。
- 判决为 PASS：进入 5 训练种子复验（v47 协议冻结列表 1/7/42/99/123），通过后作为论文主表。
- 判决为 FAIL：冻结方法路线，论文转"机制与审计"路线（协作必要性、优先级保护、剂量曲线、
  有害远飞机制链、课程依赖性），所需数据在 v24–v51 归档中已经齐备。
- 本协议变更幅度刻意最小化：单变量（微观层从"从零联训"换成"v49 冻结"），其余全部沿用
  v49 冻结配置，保证与六方法矩阵直接可比。

## 1. 动机与证据链

四条既有证据共同指向同一缺口组合："协作对齐课程的 TD3 宏观 + v49 SCA 支撑集微观"
在 50 个版本中从未被测试：

1. **课程决定 TD3 命运**：同样 cooperation_waypoint/60m 参数化、同一评估协议下，
   v45 纠偏版 TD3（继承协作课程）665.9ms，v47 从零联训版 710.9ms，差 45ms。
   v49 的"有害远飞 +16.85ms"判的是从零课程的 TD3，不是协作课程的 TD3。
2. **微观层已被 v49 修好**：SCA 支撑集残差架构下 PPO-SAC 微观 655.8ms、纯 SCA 653.5ms，
   为全场最优下层；v42 时代冻结的是 v40 病微观（尾段不稳定、无支撑集），不可比。
3. **v42 协议可执行性已验证**：冻结核验（逐元素 diff=0）、300 episode 宏观训练、
   20 种子 CRN 配对重放的整条工具链在 v42 已跑通；其失败归因于病微观 +
   centroid_waypoint/120m 旧动作语义 + [14.5,4.5,2.5] 难场景，均已在 v51 中移除。
4. **v45 交叉矩阵的预览**：TD3 宏观 + PPO 微观 = 651.6ms 为当时全场最优；本协议
   将该"拼配侥幸"转化为单一训练过程的系统产出（下层先独立预训练并冻结，上层在其上训练）。

## 2. 训练协议

- 场景：与 v49 完全一致（[12.5,5.5,3.5] 循环 × load_scale 1.15、RPGM、
  priority_demand CPU、软目标 0.9/0.1、无对偶、无功率硬门槛）。
- 微观：加载 `results/tcom_v49_support_residual_synchronous/formal/seed1/
  joint_ppo_sac/checkpoints/final.pt` 的微观组件（SCA 支撑集残差 SAC Actor），
  **全程冻结**（`freeze_micro_in_joint: true`）。SCA 求解器参数照抄 v49。
- 冻结核验（沿用 v42 标准）：加载后与源 checkpoint 的 SAC Actor、Critic、
  Target Critic、log_alpha 逐元素最大绝对差均为 0，方可开训；核验结果入 report.json。
- 宏观：TD3 从零初始化，`macro_action_mode: cooperation_waypoint`、
  `macro_waypoint_radius_m: 60.0`（v43–v49 血脉），其余 TD3 超参照抄 v49，
  仅探索衰减改为匹配 300 episode 预算（initial 20m → final 2m，decay 300）。
- 训练预算：`training_episodes: 300`，`formal_seeds: [1]`。
- checkpoint 规则：只用 final.pt。禁止 best/中间挑选（v45 纠偏教训）。

## 3. 评估协议（零训练 CRN 重放）

20 个共同随机环境种子 `8000–8019`（与 v49 完全一致，保证与六方法 per-seed 数据
直接配对）。四个臂，差值统一定义为"臂 − 主臂"，负值表示主臂更优：

| 臂 | 宏观 | 微观 | 作用 |
|---|---|---|---|
| 主臂 | v51 TD3（final.pt） | 冻结 PPO-SAC 微观 | 本文方法 |
| 对照 A | 动态质心 | 同一冻结微观 | 宏观学习价值（核心对照） |
| 对照 B | 固定初始站位 | 同一冻结微观 | 下界 |
| 诊断 C | v51 TD3 | 纯 SCA | 微观冻结对象敏感性诊断 |

PPO-SCA（v49 冠军，649.46ms）不重跑：直接使用
`result_archive/v49_independent_synchronous_seed1/per_seed_raw.csv` 同种子数据
与主臂配对。

## 4. 预注册判据

### 主判据（宏观价值门）
主臂 − 对照 A 配对差：点估计 ≤ **−5 ms** 且 95% CI 上界 < 0。
（5 ms 为 v34/v35/v37 一贯的实用显著门槛；拒绝与质心持平的叙事。）

### 冠军判据（方法主张门）
主臂 − PPO-SCA（同种子配对）：95% CI 上界 < 0。

### 非劣判据（防以恶化换时延）
- 平均功率不高于对照 A 超过 5 W（点估计）；
- 平均队列非劣（margin 取对照 A 均值的 5%，与 v42 口径一致）。

### 轨迹可解释性判据（定性，图审）
- 主臂平均路径长度 ≤ 对照 A 的 1.3 倍（v49 有害远飞形态为 1.75 倍，作排除参照）；
- 负载切换的 ±1 宏观周期内存在可辨识的定向移动（对照负载相位图人工核验）；
- 出现 v49 式远离用户云的折线漂移即判不满足。
