# v28a target 视野分解结果

> 状态：COMPLETED（2026-08-06）。本结果仅执行冻结协议中的零训练前向审计，
> 不单独触发在线算法修改，也不启动 formal。

## 1. 数据与冻结对象

- checkpoint：v24 dual-on final；
- lambda：`0.038131859182497896`，未重置；
- 测试 seed：`64000-64019`，共 20 个独立 episode；
- 状态区域：Actor 轨迹区、质心轨迹区；
- 每个 episode 每个区域 6 个分叉点，共 240 个同状态分叉；
- 每个分叉包含 Actor/联合零动作两条 H=60 分支，共 28,800 条 transition；
- 统计单位为 episode，6 个分叉点先在 episode 内聚合；
- target tail 使用冻结部署 Actor 和 v24 `macro_delay_critic_target`，不加 target smoothing。

全部 Actor/零动作分支的逐步外生轨迹哈希一致。H=30 与 H=60 的真实配对回报符号
在 Actor 区和质心区均为 100% 一致，超过预注册 90% 门槛，故本轮不是
`HORIZON_SENSITIVE`。

## 2. 预注册主结果

下表中的 delta 均为 Actor 首步动作减联合零动作；回报越大越好。

| 状态区域 | target 视野 | 与 G30 排序一致率（episode 95% CI） | 平均预测 delta | 平均 G30 delta |
|---|---:|---:|---:|---:|
| Actor 区 | n=1 | 64.17% [56.46%, 71.87%] | +0.000548 | +0.000308 |
| Actor 区 | n=5 | 95.00% [90.54%, 99.46%] | -0.000002 | +0.000308 |
| Actor 区 | n=15 | 100.00% [100.00%, 100.00%] | +0.000261 | +0.000308 |
| 质心区 | n=1 | 60.00% [49.44%, 70.56%] | +0.000355 | -0.000626 |
| 质心区 | n=5 | 92.50% [87.15%, 97.85%] | -0.000820 | -0.000626 |
| 质心区 | n=15 | 100.00% [100.00%, 100.00%] | -0.000645 | -0.000626 |

质心区是本轮关键区域：一步 target 在均值方向上错误地偏好 Actor 动作；加入 5 步实测
回报后方向转正，15 步时逐分叉排序全部与 G30 一致。该现象支持“短视 bootstrap tail
会传播错误排序”这一假设。

Actor 区的 n=5 虽有 95% 逐分叉一致率，但平均预测 delta 略为负，与平均真实 delta
方向不同，说明少数大误差样本仍可影响均值。因此不能把 v28a 表述成“视野增加后所有区域、
所有统计量单调修复”。

## 3. 判决与后续

- 冻结判决：`VALID_TARGET_AUDIT`；
- 可作出的结论：现有 target Critic 的排序误差随实测 target 视野增加而显著下降，
  bootstrap 偏差传播获得直接前向证据；
- 不能作出的结论：v28a 不能单独证明 bootstrap 是唯一根因，也不能证明改成 n-step 后
  在线 Actor 一定恢复；
- 按冻结协议继续执行同数据、同初始化和同 minibatch 的 TD/FQE 与 truncated-return
  双臂离线训练，以验证该偏差是否可通过 target 构造被稳定修复。
