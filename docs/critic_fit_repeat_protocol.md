# Critic 拟合次数单因素续训协议

日期：2026-09-08。本轮由用户批准实施，替代继续猜测最优转发形状，不改业务目标。

## 问题与范围

当前已完成 1200 个训练窗口（200 个 SAC 预训练 + 1000 个 PPO/SAC 联合窗口）。当前同 SAC 质心重放为 637.54 ms，均分为 601.43 ms；均分单帧干预未必有利，而持续干预有利。该事实不证明 Critic 唯一有错，也不证明熵或折扣机制需要更改。

本次仅检验：在既定经验和更新时点上，多一次 Critic 梯度拟合是否改善后续联合训练。不是宣称充分利用数据就必然达到最优。

## 两臂

- 来源：`results/ppo_only_unlock_continue800_to1200_seed1/at1200/final.pt`。
- 两臂均从同一个源 checkpoint 完整恢复 Actor、双 Critic、目标 Critic、熵温度、PPO、全部优化器、replay、replay RNG、全局 RNG、更新计数和 PPO 待更新样本。
- 两臂各增加 200 个窗口，固定到总窗口 1400（预训练仍为 200，联合累计 1200），只使用最后权重，不选中间最好点。
- control：`sac_critic_steps_per_update=1`，与原一梯度实现数值等价。
- two_fits：`sac_critic_steps_per_update=2`。
- 除该参数外，两臂配置逐字段相同。两臂使用相同后续训练场景序列，独立保存各自学习状态。

## “两次”具体是什么意思

一个既有 SAC 更新时点只抽取一次 batch，计算一次固定 target。Critic 对这一批样本及这个 target 连续做两次梯度更新，第二次重新前向计算当前 Q。不是复制旧梯度，也不再次抽样或重算 target。

Actor、熵温度、目标网络、PPO 的更新时点不增加；Actor 学习率、Critic 学习率、梯度裁剪、目标网络 tau、batch size、replay 容量、奖励、折扣、场景、状态、动作和探索日程均不变。

新的 Critic 值会自然影响后续 Actor 梯度和训练轨迹，这属于实验效应；并不要求两臂训练后动作相同。PPO 的 KL 提前退出次数可能随训练轨迹不同，允许其按原规则自然变化。

旧字段 `sac_critic` 继续表示 SAC 更新事件数，以免改变 Actor warmup/policy-delay 的计数语义。新增 `sac_critic_gradients` 记录真实 Critic 优化器步数，`sac_target` 记录目标网络更新次数。旧 checkpoint 缺少新计数时按原来一事件一梯度一目标更新恢复。

第二次 Critic 拟合不额外抽随机数。普通续训默认仍禁止学习配置变化；只有本实验显式授权的 Critic 拟合次数可覆盖，且必须写入恢复审计。

## 评估与判读

- 训练中仅保存进度、日志及既定 checkpoint；最终才做固定评估，不因中期好坏改预算。
- 每臂最后权重在 33500、33501、33502 三个既有开发场景各评估 900 秒。
- 同时保留完整 PPO+SAC、同一末次 SAC 的质心对照、均分诊断。后两者不是独立训练的正式竞争方法。
- 完整方法报告 J、加权/高优/低优时延、完成率、平均及期末队列、逐种子末段队列斜率、功率。时延/J 差值按处理臂减控制臂，负数有利。
- 保留相对源 1200 窗口的差值，用以区分普通续训收益与增加拟合次数的增量。
- 不预设必须低于 600 ms，不为奖励某个动作形状改变目标，不把单训练种子/三个开发场景冒充多训练种子的统计证据。
- 若处理臂未胜出或队列指标退化，如实报告并保留一拟合默认值，不自动把额外拟合升级为主方法。
- 本次只检验同一 batch/target 的重复拟合，不涵盖更频繁采集、独立 batch 多更新、多步 target、奖励塑形或整个 Critic 架构。

## 完整性与预算

所有结果写入 `results/critic_fit_repeat_1200to1400_seed1/`，源 checkpoint 不覆盖。运行前完成一拟合旧实现逐位回归、两拟合更新节奏/RNG 测试及续训测试。运行后核对源码哈希、恢复状态、两臂梯度次数、Actor/PPO/目标网络更新事件数以及评估 CRN。

仍是现有“微观预训练后两层异频同步更新”的分层强化学习主线。不引入 QA、教师、门控、强制均分、强制本地或单向分担动作。
