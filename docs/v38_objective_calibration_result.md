# v38 软目标权重校准结果

## 判决

**权重已冻结，仅用于下一轮 SAC 重训；本轮不是正式性能证据。**

- 物理交换率保持预注册值：`rho=0.25 ms/W`；
- 训练配置使用精确值：`w_D=0.960408028711155`、`w_E=0.0395919712888449`；
- 论文展示可写为 `0.96/0.04`；
- 正式门禁必须使用与 `5000--5019` 不相交的全新 20 个 CRN 种子。

## 校准重计分

- 基准负载：`4.640 ms / 19.849 W = 0.234 ms/W < 0.25 ms/W`，新目标差
  `Delta J=+0.000461`，仍拒绝协作；
- 增强不均衡负载：`10.022 ms / 19.998 W = 0.501 ms/W > 0.25 ms/W`，新目标差
  `Delta J=-0.005800`，偏好协作。

该结果只说明新目标与声明的交换率一致，不得作为正式门禁 PASS 使用。

## 后续评估哨兵

对任一学习策略相对 P0 报告：

`实际交换率 = 时延收益(ms) / 额外平均功率(W)`。

当额外功率大于 0 时，该值必须与 `0.25 ms/W` 对照；若策略同时降低时延和功率，标记为
Pareto 占优，不用比值掩盖；若时延无改善，则直接判为无效购买。
