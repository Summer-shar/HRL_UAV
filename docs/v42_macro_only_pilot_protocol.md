# v42 最终栈宏观 TD3 单因素 pilot（FROZEN）

## 研究问题

在 v40 final 微观 SAC、校准软目标、增强负载不均衡和 RPGM 用户移动均固定后，宏观 TD3
是否能学到优于动态业务质心跟踪的连续轨迹策略？

该实验只回答宏观层可学习性。微观 Actor、Critic、温度和 replay 均不更新，因此结果不能
宣称“两层联合训练已经成功”；若宏观层通过，下一阶段才测试低速联合微调。

## 冻结设置

- 微观策略：`tcom_v40_micro_warmstart/formal/seed1/micro_pretrain/checkpoints/final.pt`；
- checkpoint 来源 stage 显式冻结为 `formal`，smoke 与 pilot 均加载同一份权重；
- 微观层：全程冻结，不加载 replay，不恢复优化器；
- 场景、物理模型、目标权重和宏观 TD3 超参数：与 v40 配置一致；
- 宏观训练：seed=1，固定 300 episode，n=1，Q1 Actor；
- 固定使用 ep300 `final.pt`，不按训练结果选择中间 checkpoint；
- 不把固定 60 m 规则的 3.594 ms 与 TD3 收益相加。

## 执行门槛

1. smoke 必须证明加载的是 v40 final，且微观参数在训练前后哈希不变；
2. 正式 pilot 每 50 轮固定评估一次，完整保存宏观 replay 和 checkpoint；
3. ep300 后，在 20 个全新 CRN 种子上重放 TD3 final 与匹配 P0 动态质心策略；
4. 主判据：TD3 相对 P0 的配对端到端时延差 95% CI 上界小于 0；
5. 共同判据：软目标差 95% CI 上界小于 0，平均队列不劣；
6. 功率、实际 ms/W、逐链路流量和轨迹仅描述性报告，无硬功率门槛；
7. 若 pilot 不通过，不启动五训练种子矩阵；若通过，再预注册低速联合微调。

## 解释边界

- 固定 60 m 规则只是一条手写策略，不是位置收益上界；
- 单 seed pilot 只能作 go/no-go，不能作论文最终显著性结论；
- 若冻结微观下 TD3 仍失败，可归因于当前宏观学习器/信号组合，但不能外推为所有轨迹算法
  都无效；
- 若冻结微观下通过而联合微调失败，才支持跨层非平稳是主要瓶颈。
