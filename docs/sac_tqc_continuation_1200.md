# SAC/TQC 双臂续训至 1200 窗口

本次授权：2026-09-08，查看 1000 窗口结果后，用户同意两臂各追加 200 个联合训练窗口。属于探索性续训，不追溯声称为事先冻结的 1200 窗口实验。

## 不变项

- 源实验：`results/sac_tqc_fresh1000_seed1`。每臂原有 200 窗口微观预训练和 800 窗口联合训练。
- PPO+Direct SAC、PPO+Direct TQC 各加载自己的 `final.pt`；不重训微观，不互换权重，不引入教师、QA 或 SCA 锚定。
- 完整恢复 Actor、Critic、目标网络、熵温度、全部优化器、replay、待更新 PPO 样本、更新计数器和随机状态。恢复逐项核验必须通过。
- 场景、状态、动作、奖励、网络、学习率、探索调度、更新频率全部不变；唯一训练配置改动是 `joint_windows: 800 -> 1000`，累计总窗口 `1000 -> 1200`。
- PPO 保留原有 KL 提前停止规则，因此两臂的 PPO 更新事件数相同，但内部梯度步数不要求相同。不得重置任一臂自己的梯度计数器。

## 执行

顺序运行 SAC、TQC，每臂追加 200 个窗口，结束后统一回放，训练中不插入性能评估。每臂恢复时 replay 累计计数为 540000，结束应为 648000；Critic 新增 5400 次更新事件、10800 次梯度拟合，微观 Actor 新增 2700 次，PPO 新增 20 次更新事件。

每 3 个窗口组成一段连续训练轨迹，在完整采样边界保存检查点。新增曲线检查点为总窗口 1102 和 1200，不伪造第 1100 窗口的读数。不声称续训与最初就规划 1200 窗口逐位等价，因为旧终点已经执行过末段更新。

```powershell
.\.venv\Scripts\python.exe -u scripts\continue_sac_tqc.py --source results\sac_tqc_fresh1000_seed1 --output results\sac_tqc_continue1000to1200_seed1
```

原始 1000 窗口检查点和结果不覆盖，源文件哈希在运行前后核验。新结果独立保存；曲线合并历史时保留实际全局窗口编号。

## 评估与停止

- 开发场景仍为 33000、33001，最终比较仍为 34500 至 34504，各 900 秒。已经查看过这些场景，不能称为全新留出测试。
- 同时比较两臂的 1200 窗口终点，以及每臂相对其自身 1000 窗口终点的配对增量。固定取 final，不挑 best。
- 报告加权完成时延、高低优先级时延、软目标 J、完成率、未完成任务、连续队列和功率；保留同微观策略下 PPO 与质心的反事实比较。
- 仅一个训练初始化，五个环境种子的区间不代表多训练种子稳健性。开发曲线和最终五场景均值分开呈现。
- 两臂到 1200 窗口即停止，不按是否突破 600 ms 自动延长，不把一次改善称为已经收敛。

1000 窗口参考：PPO+SAC 加权时延 635.577 ms，PPO+TQC 614.321 ms；二者分别作为自身续训的旧终点，而非预设新终点必须达到的数值。
