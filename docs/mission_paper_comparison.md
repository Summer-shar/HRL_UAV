# Mission论文数据第一批补齐协议

本轮由用户要求补齐论文对比与参数图授权。预先固定下列范围，不按结果调整。

## 范围

- 不改生产实现、奖励、CPU、无线公式、动作映射或网络，不训练、不写或采样replay。
- 基于Stage4A三个独立PPO初始化201/202/203的原window120终点，SAC101 window2000。
- 仅33600、33601两个已用开发场景，每次连续900秒；300/600秒不reset。
- 同一冻结PPO权重下比较SAC、Local、Uniform、Random。不同微观策略可改变队列，并经宏观观测反馈改变后续轨迹；没有强行固定UAV轨迹。
- 因此这是共享宏观策略的微观消融，不是各方法独立训练的完整方案竞赛。
- Random每0.5秒按源及优先级分别采样Dirichlet(1,1,1)，使用独立于环境的PCG64随机流；并非均分规则。
- Predictive+SAC另列强规则参考，不改名为PPO。

## 参数点及预算

中心为负载倍率1、U2U6MHz。另取负载倍率0.8、1.1，以及U2U3、4.5MHz。
每次仅改变phase_loads同比例倍率或U2U带宽，保持不均衡比例。
不修改已有配置文件，有效配置完整写入本轮manifest。
共5配置x(3 PPO初始化x4微观策略+1 Predictive参考)x2场景=130条记录。
复用来源一致的原中心配置8条SAC记录，新增122次900秒评价。
21次20秒功能smoke先于正式评价，包括旧PPO和Predictive轨迹/观测/队列的前缀核对。
同一参数点的各方法逐帧核对外生过程；同负载不同带宽也核对外生过程。
改变负载后不要求任务出生相同，不伪称它们是相同任务流。

## 输出与边界

保留逐场景、逐宏观初始化、汇总、配对差、队列/路由/链路/轨迹和实际耗时。
参数图表示冻结权重的运行参数敏感性，不代表每个参数点重训后的最优性能或跨场景泛化。
三个PPO初始化共享SAC101，误差不能称作三次完整HRL独立训练的误差。
所有预设结果保留，不用改变基线、删seed或筛参数制造明显领先。
600窗口续训三个终点另行展示，不挑较好seed替代120协议。
