## A. 原门禁结论保持不变

- P1 相对 P0 的整段配对时延改善为 `25.861 ms`，95% CI 为
  `[17.729, 33.994] ms`，位置价值门槛成立。
- P1 平均系统功率为 `845.431 W`，超过原门禁预算 `840 W`，因此原门禁
  判决仍为 FAIL。
- 本补充协议不得被用于将原门禁改判为通过。

## B. 功率归因审计

数据来源：`result_archive/load_switch_gate_power_audit/`。

- P1-P0 系统平均功率增量为 `13.474 W`，95% CI 为
  `[13.013, 13.934] W`。
- 推进功率贡献 `13.051 W`，其中部署瞬态机动项 `0.5*m*v^2` 贡献
  `11.899 W`；CPU 仅增加 `0.461 W`，通信净变化为 `-0.038 W`。
- 分项记账最大闭合残差为 `4.495e-09 W`。
- 基于模型参数和冻结 P1 机动协议得到场景/协议特定的保守功率包络：

  `584.290 + 270.000 + 8.910 + 0.202 + 13.940 = 877.343 W`。

该数值不是应用给定的硬功率预算，也不是动态对偶的主操作点；它仅用于定义
近无约束扫描端点。

## C. 预算规则（冻结）

| 系统平均功率预算 | 角色 |
|---|---|
| `840 W` | 主约束点、主表操作点和动态对偶 pilot 点 |
| `860 W` | 中等约束灵敏度点 |
| `880 W` | 宽松/近无约束端点，不得作为动态对偶有效性的证据 |

- `840 W` pilot 若失败，不得在看到结果后自动将 `860 W` 升格为主操作点。
- 正式约束判定采用单侧 95% 功率上置信界（UCB95），而非只比较样本均值。
- 预算灵敏度实验必须注明是逐预算重新训练、预算条件化策略，还是冻结策略诊断；
  三种口径不得混写。

## D. P1 的论文身份（正式训练前必须预注册）

冻结 P1 保留为“负载切换场景存在非平凡位置价值”的举证策略。由于它在
`840 W` 下不可行，正式主表必须在训练前选择并冻结以下一种处理：

1. 将 P1 标为功率不可行的诊断参考，不参与可行策略间的性能排名；或
2. 另行预注册满足 `840 W` 的能量感知启发式 P1'，并将 P1' 作为公平基线。

不得在正式结果出来后根据排名选择处理方式。

## E. 已核验的动态对偶现状

1. v23 实际运行 `objective_mode=constrained_delay`，但
   `energy_dual_lr=0`；400 轮训练中系统乘子始终为 `lambda=0`。
2. 宏观能耗 Critic 持续训练，但乘子为 0，因此其输出未进入 Actor 的实际优化。
3. 固定权重 20 的功率违约项只进入宏观 TD3 回放奖励；微观 SAC 不使用该项。
4. 系统级乘子当前未进入宏观和微观观测，而 `priced_maxweight` 会用乘子改变
   CPU 能耗价格及状态转移。直接开启非零乘子会破坏观测的 Markov 闭合性。
5. 加权目标路径仍保留，但 v23 正式运行并非 `0.7*delay+0.3*energy`。

## F. 动态对偶开机协议（冻结）

### F.1 工程前提

1. 将归一化系统乘子加入宏观与微观观测；
2. 本实验选择纯拉格朗日形式，因此固定功率违约罚项设为 0；若后续保留该项，
   必须另行定义为增广或精确罚项方法并重新预注册；
3. 微观状态维度改变后重新预训练 SAC，不兼容旧状态维度的 checkpoint；
4. 验证 `lambda -> CPU energy price -> CPU frequency -> system power` 的响应链；
5. 增加状态维度、乘子可观测性、CPU 单调响应和 checkpoint 恢复回归测试。

### F.2 单因素隔离

- 动态对偶 pilot 不与中性动作覆盖修改合并。
- 先冻结覆盖方案，再在同一覆盖方案上比较对偶关闭与开启；资源允许时可另行
  预注册完整因子实验。
- pilot checkpoint 不得继承到 formal；formal 必须从干净网络、优化器、回放、
  RNG 和乘子状态重新开始。

### F.3 840 W pilot 验收

1. 当平滑功率高于目标时，乘子按冻结更新规则非减；低于目标时允许回落至 0；
2. 乘子变化必须同步反映到 CPU 能耗价格，CPU 最优频率对能耗价格呈非增关系；
3. 后期评估的系统平均功率 UCB95 不超过 `840 W`；
4. 乘子与约束残差满足经验互补松弛：可行且非紧约束时 `lambda=0` 属于正确结果；
5. 相对同配置的对偶关闭对照，时延不得出现未预注册的显著崩溃；
6. 任一响应链测试失败均视为工程失败，不得进入长训练。

## G. 执行边界

执行顺序固定为：状态闭合与测试 -> 840 W 短 smoke -> 840 W 单因素 pilot ->
结果审计。pilot 通过前禁止三种子长训练和正式方法矩阵。
