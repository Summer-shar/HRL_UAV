## 2. 冻结判决

truncated-return 臂未通过训练集拟合门禁：

| 数据区域 | TD/FQE 排序一致率 | truncated-return 排序一致率 |
|---|---:|---:|
| train Actor 区 | 40.00% | 45.42% |
| train 质心区 | 42.50% | 44.17% |
| test Actor 区 | 50.00% | 58.33% |
| test 质心区 | 42.50% | 45.00% |

预注册要求 truncated-return 训练集一致率不低于 90%，且测试 Actor 区必须为
`CORRECT`。两项均失败，因此最终判决固定为：

`INVALID_OR_INCONCLUSIVE`

该结果既不支持也不否定 bootstrap 偏差传播，更不能据此把 U2U 表征宣布为根因。

## 3. 失败原因审计

truncated-return 臂的绝对回报拟合结果为：

- 全训练集目标均值 -0.7820、标准差 0.4172、RMSE 0.0543、R² 0.9831；
- 固定剩余视野 h=30 后，目标标准差 0.0712、RMSE 0.0656、R² 仅 0.1520；
- Actor 区真实首步动作差标准差 0.00295，h=30 绝对 RMSE 是其 22.25 倍；
- 质心区真实首步动作差标准差 0.00373，h=30 绝对 RMSE 是其 17.59 倍；
- 三个初始化的 truncated-return loss 在早期下降后长期停在约 0.004-0.01，
  未显示“只需继续增加更新次数”即可跨越数量级差距的趋势。

因此全局高 R² 是被“剩余视野”这个强变量主导的假象。该离线网络没有解析同一状态下
两个动作之间千分位的因果差异。CRN 已降低真实配对差的方差，但独立绝对 Q 回归没有利用
配对结构，而是在分别拟合两个约为 -1.4 的大数后再相减，回归误差淹没了动作优势。

## 4. 与 v28a 的关系

v28a 不训练新网络，直接在同一反事实分支上分解现有 target：质心区排序一致率从 n=1
的 60% 提高到 n=5 的 92.5%、n=15 的 100%，且均值方向从错误转为正确。该前向证据仍然
有效。v28 双臂失败只说明“用普通绝对 Q 回归复现这一差异”的验证管线分辨率不足，
不能反向抹掉 v28a。

## 5. 下一步建议（尚未执行）

不建议事后增加更新轮数、挑 checkpoint 或直接加入 pairwise loss 挽救本轮。若继续验证
bootstrap 假设，优先另行预注册一个在线 n-step 单因素 pilot：以 v24 dual-on 为对照，
仅把宏观时延 Critic 的一步 target 改为 n=5 target；n=5 是 v28a 中同时在 Actor 区和
质心区越过 90% 一致率的最短视野。该实验直接回答“扩大 target 视野能否修复真实在线
Actor-Critic 漂移”，比再次训练绝对回报 FQE 更贴近最终算法。

若仍要求离线确认，则必须另行定义“配对动作差回归”协议并明确其仅为因果诊断器，
不能再称为标准 FQE Critic；该改动会利用 CRN 配对结构，属于新的训练目标，不能追溯修改 v28。
