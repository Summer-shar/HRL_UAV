# v45 公平方法筛查实施纠偏记录

> 状态：事后工程纠偏。冻结协议、训练预算、评估种子、主指标和检查点规则均不变。

## 发现的问题

首轮实现审计发现，冻结协议要求第二阶段从第一阶段的 `final.pt` 继续训练，
但 TD3-SAC 复用的 v44 运行从 v43 `best.pt` 启动；PPO-SAC、PPO-SCA 与
No-Coop 均从各自第一阶段 `final.pt` 启动。该差异使首轮比较不满足统一的
检查点来源规则，并且偏向 TD3-SAC。

## 纠偏方式

1. 不修改冻结协议与任何算法超参数；
2. TD3-SAC 改从 v43 `final.pt` 启动，按原计划重新训练第二阶段 200 episode；
3. 固定使用纠偏运行的第二阶段 `final.pt`，不选择中间或 `best` 检查点；
4. 其余方法的现有第二阶段结果保持不变；
5. 重新运行种子 8000--8019 的统一 CRN 评估，并覆盖 v45 筛查报告与图片；
6. 旧 v44 结果保留在原目录，只作为实施审计记录，不进入最终筛查排名。

本次操作修复的是协议执行偏差，不是依据性能结果修改实验规则。
