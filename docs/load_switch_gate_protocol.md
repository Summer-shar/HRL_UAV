# 负载切换门禁实验规格（Load-Switching Gate Experiment Spec）

> 状态：FROZEN。本文档定稿后，P1 策略参数与验收判据不得在看到结果后修改。
>
> 前置结论：论文采用“学习层超越最强启发式”的强主张路线；本实验是新场景转正前的唯一门禁。实验只做重放，不训练网络。通过后才投入正式训练；不通过则按第 7 节只调整一次并复测。

## 1. 目的与判决

验证负载切换场景中是否存在纯质心跟踪无法捕捉的位置增益。

- **通过**：P1（因果负载感知）相对 P0（纯质心跟踪）的整段配对时延收益大于 5 ms，且 95% 配对置信区间排除 0。此后冻结场景并进入 TD3-SAC 与全部基线的正式训练。
- **不通过**：按第 7 节只调整一次参数后复测；仍不通过则回到论文叙事讨论，不再继续加码。
- P2（预知上限）只判断收益是否依赖负载预测状态，不进入主表。

## 2. 场景定义

在现有 v22/v23 动态用户配置上只增加负载阶段循环，其余物理与协议参数保持不变：通信模型、CPU 10 GHz、用户 Gauss-Markov `pi/4` 移动、`load_scale=1.15`、系统平均功率预算 840 W。

| 项目 | 冻结值 |
|---|---|
| 负载阶段 1 | `[12.5, 5.5, 3.5]` Mbps |
| 负载阶段 2 | `[3.5, 12.5, 5.5]` Mbps |
| 负载阶段 3 | `[5.5, 3.5, 12.5]` Mbps |
| 门禁切换时钟 | 每 10 个宏观周期切换一次，即宏观步 10、20 |
| episode | 300 s，30 个宏观周期，恰好包含三个负载阶段 |
| 正式训练切换时钟 | 本实验不使用；未来采用 8--12 个宏观周期的随机驻留时间 |

三个阶段总负载相同，只循环改变区域间分布。

### 切换语义

每个宏观周期开始时，必须先完成负载阶段切换（调用 `env.set_zone_target_loads(new_loads)`），再调用 `get_macro_state()`，最后生成宏观动作。禁止让策略晚一个周期观察到新负载。

状态不提供未来负载或切换倒计时。P0/P1 只能使用因果信息；只有 P2 可读取下一阶段信息，并明确标为非因果上限。

## 3. 实现与审计要求

1. 切换触发器位于宏观循环入口、原始状态提取之前。
2. 运行配置必须显式启用 `macro_load_state=1`、`macro_flow_state=1`、`macro_capacity_state=1`。
3. 审计宏观状态是否包含 episode 步数或进度特征，并在结果中注明。
4. 每宏观周期记录负载阶段编号、是否发生切换、实际链路流量矩阵 `F_mn`。
5. 三种策略对同一测试种子必须具有相同的用户移动与任务到达轨迹；通过外生轨迹哈希逐种子核验。

## 4. 三种固定策略

### P0：纯质心跟踪

所有 UAV 始终输出 `centroid_waypoint` 的零残差，即目标点等于各自区域的动态业务质心。

### P1：因果负载感知

- **触发**：通过当期可观测的区域期望负载排序识别负载切换；新角色从切换后的下一个宏观周期生效，不使用未来信息。
- **新重载机**：当期期望负载最高区域对应的 UAV。
- **支援机**：其余两机中 `norm_q_high + norm_q_low` 最小者，即剩余计算能力最大、队列最短者。
- **支援动作**：目标点为自身区域质心加上朝新重载机当前位置方向的 40 m 偏移；实际运动受每周期 20 m 位移上限约束，约两个周期到位；此后保持该偏移直至下一次切换。
- **其余动作**：新重载机与第三架 UAV 采用零残差质心跟踪。

初始阶段不是一次负载切换，但 P1 在 episode 开始时依据首阶段当前可观测负载建立初始角色。负载切换当期结束旧角色并执行零残差，新角色从下一宏观周期生效。该实现约定在看到结果前固定。

禁止在看到结果后修改 40 m、角色判定或触发规则；任何修改都视为第 7 节规定的唯一一次复测。

### P2：非因果预知上限

每次切换前 5 个宏观周期，支援机提前按 P1 的角色与动作规则向下一阶段的新重载机移动；其余行为与 P1 相同。P2 只作为非因果上限，不进入论文主表，也不能作为正式的“位置有价值”证据。

## 5. 评估协议

| 项目 | 冻结值 |
|---|---|
| 测试种子 | 20 个共同随机种子（CRN） |
| episode | 300 s，30 个宏观周期，三个负载阶段 |
| 主指标 | 整段优先级加权任务级端到端时延（ms），与四位置审计口径一致 |
| 副指标 | 切换后前 5 个宏观周期的加权任务时延、逐链路 `F_mn`、U2G/U2U 活动时间、系统平均功率 |
| 配对量 | `delta_xi = D_P1(xi) - D_P0(xi)` |
| 统计 | 配对均值、双侧 95% t 置信区间、配对标准化效应量；逐种子原始值必须落盘 |

过渡窗定义为宏观步 `[10, 14]` 与 `[20, 24]`。窗口时延使用在窗口内完成任务的完整端到端时延，并通过环境累计任务计数与累计时延的差分计算。

## 6. 预注册验收判据

1. 主判据：`mean(delta) < -5 ms`，且 95% CI 上界小于 0，判为通过。
2. 辅助结果只用于解释，不改变主判决：
   - 主判据未过但过渡窗收益显著：切换周期可能过长，第 7 节优先考虑选项 A。
   - P1 无效但 P2 有效：收益存在但依赖预测信息，正式训练需提供因果负载预测特征。
   - P1、P2 均无效：当前物理设置不存在足够的位置增益，第 7 节考虑选项 B，或停止场景加码。
3. P1/P2 的 20-seed 系统平均功率均值不得超过 840 W；超预算即判负，不作事后解释。

## 7. 失败后唯一允许的调整

失败后只允许选择以下一个杠杆，先声明，再复测一次：

- **选项 A（时间侧）**：切换周期从 10 缩短为 6 个宏观周期。
- **选项 B（瓶颈侧）**：CPU 从 10 GHz 提高到 16 GHz，降低计算瓶颈占比并提高通信与位置敏感度。

第二次仍不通过则停止加码。

## 9. 明确不做

- 不训练网络，不修改奖励、shaping 或通信模型；除非触发第 7 节选项 B，否则不修改 CPU。
- 不增加距离惩罚或 Advisor。
- 不运行 27 组合联合扫描。
- 不将 P2 作为正式位置价值证据。

## 10. 与论文主线衔接

本门禁与旧场景的“中性覆盖修漂移”实验并行，彼此不依赖。两者都通过后，负载切换场景转为论文主场景，正式训练矩阵为：

`TD3-SAC(+覆盖) / PPO-SAC / SCA / No-Coop / 固定锚点 / P0 质心跟踪 / P1 手写规则`，每种方法 3 个训练种子。

P1 必须进入主表；学习层的胜负线是追平并超越 P1，而不只是超过 P0。
