## 可确认的失败机制

1. G1 是悬停下层 SAC 的失败，PPO 尚未参与，不能据此判定“上层学习信号弱”。所有悬停模式上传和 ready 的 pool 阶段时延完全相同。SAC 对三等分的 CPU 阶段增加 0.698281 s，U2U 阶段减少 0.055089 s，净增加 0.643192 s；差值来自计算排队分配，而不是本次上传条件变差。
2. SAC 高优截断时延降低 6.49%，低优增加 317.76%。6249 个未完成中 6209 为低优。不能只看已完成 p95=2.8 s；最老未完成低优已达 338 s，截断指标揭示这一尾部。
3. 这不是已由现有奖励证明合理的节能交换：SAC 的 cost/s 更高。相对三等分每秒额外成本 4.586432，其中 holding 4.517564（98.50%），能量项 0.068868。SAC 总能量也稍高。
