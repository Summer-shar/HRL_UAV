# v47 独立初始化、同步联合训练协议（FROZEN）

## 目的

正式比较完整 HRL 方法，而不是复用公共微观策略的控制变量诊断。

## 训练阶段

- 每个方法、每个训练种子独立初始化网络、经验池和优化器。
- 前 200 轮只训练该方法自己的 SAC；学习型宏观方法统一采用零残差动态质心。
- 后 800 轮中，宏观 TD3/PPO 与对应 SAC 均持续更新。下层执行结果按大周期聚合后反馈上层。
- 联合阶段恢复该方法自己的 SAC replay 与优化器；禁止共享其他方法的 checkpoint。
- 固定站位-SAC和动态质心-SAC分别训练自己的 SAC；其宏观规则不学习。
- PPO-SCA 与 No-Coop 使用各自原生求解器，不伪造不存在的微观预训练。

## 正式方法

1. TD3-SAC（主方法）
2. PPO-SAC（宏观算法对比）
3. PPO-SCA（微观算法对比）
4. No-Coop（协作消融）
5. 动态质心-SAC（轨迹规则基线）
6. 固定站位-SAC（无轨迹优化基线）

## 公平性

- 训练种子固定为 1、7、42、99、123。
- 每个正式模型用相同的 20 个环境种子做最终评估。
- 学习型宏观方法均获得 800 轮宏观训练预算。
- 所有 SAC 方法均获得 200+800 轮微观训练预算。
- 固定使用最终 checkpoint，不按结果挑选 best。
- 训练种子是统计单位；20 个环境种子只用于降低单个模型的评估方差。

## 结果边界

v46 公共 SAC 结果仅保留为控制变量诊断，不得进入正式主表。CPU/负载扫描只能在 v47 基础方法完成且训练稳定后启动。
