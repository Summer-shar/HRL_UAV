# 本机字体

这些字体从作者本机 Windows/Office 的已安装字体复制，供本人的私人写作工程在 Overleaf 中使用。不要把该文件夹作为公开字体下载包分发；团队共享或公开仓库应遵守相应字体授权。

标题：simhei.ttf（SimHei）

正文：simsun.ttc（SimSun，集合中的首个字体）

中文作者姓名：STKAITI.TTF（STKaiti）

英文：times.ttf、timesbd.ttf、timesi.ttf、timesbi.ttf（Times New Roman 的常规、粗体、斜体、粗斜体）

上传工程时必须保留本文件夹。文件式加载用于避免 Overleaf 找不到系统字体而退回 Fandol。
